- 원본 국문과 구현 국문의 데스크톱 화면을 직접 확인했다. 원본 CSS·폰트·사진·본문 레이아웃이 적용됨을 확인했다.
- KO → EN → JA → ZH 이동과 언어별 본문·html lang을 확인했다.
- 예약 메뉴의 8개 채널과 닫기 버튼을 확인했다.
- FAQ 첫 항목이 펼쳐지고 답변이 보이는 것을 확인했다.

- 영상 Next 버튼 클릭 후 가로 스크롤 위치가 286으로 이동했다.
